GitHub documents a workspace-edit caveat for discarded Fusion drafts

GitHub's Fusion documentation says discarding an intermediate draft does not automatically undo workspace edits already made by that draft.

Published October 29, 2026 · Reviewed October 29, 2026

Source-reported; not independently tested

Observed October 29, 2026 · Documentation change: October 28, 2026

GitHub's Fusion documentation says that discarding an intermediate draft does not automatically reverse workspace changes already made by that draft, including file edits.

The same document describes intermediate drafts being revised or discarded while the user receives a final response. These are documentation statements, not observations from a Scout execution.

Source and freshness. The pinned Markdown matches the file's October 28 revision, 8e7396e5e2e02bac9caba10c8d944f938bcd9b52, byte for byte. Its file history showed no later change when checked October 29.

Inspection limits. Public documentation and repository history only. No Fusion session, implementation, rollback behavior, account eligibility or performance was tested. This report makes no recommendation about adopting Fusion.
