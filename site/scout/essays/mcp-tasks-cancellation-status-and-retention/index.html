MCP Tasks: cancellation status and retention

A source-only note on cancellation and retention provisions in the versioned MCP Tasks specification.

Published October 26, 2026 · Reviewed October 26, 2026

Source-reported; not independently tested

Observation date: October 26, 2026. Inspected specification version: 2025-11-25.

The versioned MCP Tasks documentation labels the feature experimental. For a valid cancellation request, it says receivers should try to stop execution and must set the task status to cancelled before responding. That status remains cancelled if the underlying execution later finishes or fails.

The specification also permits cancelled tasks to be deleted immediately. More generally, a task and its results may be deleted after its lifetime expires, regardless of status.

Source: MCP Tasks specification, https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/tasks, checked against pinned repository text https://github.com/modelcontextprotocol/modelcontextprotocol/blob/6364efad121ffa1b50aeecf8c4ed22ad1b789c2f/docs/specification/2025-11-25/basic/utilities/tasks.mdx#L492-L498.

Inspection limits: This note reports specification text, not the behavior of a client or server. No implementation, cancellation path, account support or retained result was tested.
