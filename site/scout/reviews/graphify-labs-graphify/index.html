What it is. Graphify-Labs presents Graphify as an open-source, local code-mapping tool for developers and coding assistants. It proposes a queryable graph of code relationships so a developer can answer cross-file navigation questions without rediscovering the same paths by hand. Documentation also describes optional semantic mapping of documents and media; that is a different data-exposure decision. Project description.

What we inspected. At revision 847a93f, we read the README, security policy and license. We did not inspect the parser or query implementation, install the tool, build a graph or measure savings. The described tree-sitter parsing and extracted-versus-inferred edges remain documented design claims in this review.

Recommendation: EXPERIMENT, subject to separate authorization, with a small public code-only fixture.

For GhostMesh, the map could make repository navigation cheaper. It would still be a derived map, not the authority for ownership, permissions or completion. The question is concrete: which files call this function, and what might a change affect?

Incumbent comparison. Its incumbent is ordinary repository search and direct source reading. A useful comparison would ask the same fixed cross-file questions using both methods, check answers against source, then repeat after a controlled source change to expose stale-graph behavior. Measure correctness, elapsed effort and refresh cost before considering integration.

Everyday usefulness. For an everyday user who does not work with code, direct value is limited. Document and media mapping may sound more approachable, but it changes the privacy boundary: the documentation says semantic extraction may send content to a configured model backend. Security policy.

Risk, license and effort. The open-source repository carries Apache-2.0; the promoted hosted Cloud service is a separate offering, not evidence that the local tool delivers its advertised savings. A bounded code-only comparison is narrower than integrating hooks, MCP or hosted services. Indexing, parser dependencies and stale-map handling still need ownership. License, README.

Still unknown. README and security-policy review establishes the documented design, not implementation correctness. No parsing, querying, security controls, benchmark, privacy guarantee or claimed token saving was verified. Graph accuracy on GhostMesh repositories, refresh reliability, total maintenance effort and maintainer response quality remain unknown. The security policy acknowledges residual prompt-injection risk in semantic extraction. Do not upload private documents or enable optional network integrations on this recommendation.
