# Integration plan: designed adapters, inactive

## Source custody and no duplicate writer

The Readers generator is a local static compiler from checked-in Reader HTML and a reviewed projection source file. It writes only generated files under this repository's `site/`. It does not invoke SharePlane, Control Tower, Tony Brain, Library Atlas, Netlify, Cloudflare, or a database.

SharePlane Platform #1471 names #929 as the governed edge admission lane and #409/#1403 as reader projection lanes. Draft graph/publication work exists there. The Readers `cites` link is a local transcription of the public evidence ledger, not a Work-to-Work relationship. Do not map it into `control/kos` automatically or advance a SharePlane census/publication counter. The active SharePlane writer and graph inventory must be reconciled afresh before any adapter implementation.

Tony Brain `80-private/` was not read. Its `AGENTS.md` makes that compartment deny by default. Library Atlas ADR-0001 places corpus truth in the owner control plane and source systems. A public adapter must consume an explicitly public, owner-authorized export, never query broad private indexes and filter after retrieval.

## Adapter designs

### SharePlane public Work consumer

1. **Input:** an existing immutable, already public SharePlane Work representation and its canonical Work/relationship admission receipts; do not infer admission from a public URL or a source-declared link.
2. **Identity:** retain canonical SharePlane Work and relationship IDs as external references; use a projection-local ID only for the transport record. Never mint a second canonical Work ID.
3. **Claims:** accept only claim-level public evidence with exact immutable source/version hash, source locator, explicit epistemic posture, classification and owner release decision.
4. **Output:** a versioned read-only JSON/JSON-LD/HTML projection and deterministic manifest from the qualified public snapshot. No callback, import, registration, graph write or publication event.
5. **Gate:** source owner verifies that #929 admission, #409/#1403 reader behavior, #948 public census, disclosure policy, exact current head, writer claim and immutable public release agree. Privacy and graph review precede any implementation PR. Production/public release remains separate.

### Library Atlas / Tony Brain public evidence bridge

1. **Input:** a separately approved, public-safe export from the authoritative Atlas control plane or Tony Brain source owner. The export must carry object ID, exact source SHA-256, version, sensitivity, rights, provenance and an explicit public disclosure decision.
2. **Processing:** read-only; verify source hashes and audience before extraction, following Atlas `CONTENT_PROJECTION_BOUNDARY.md`. No direct `80-private/` read, protected retrieval, embeddings, personal summaries, model inference or database write.
3. **Output:** a bounded public projection with external owner-controlled IDs retained as references, uncertainty preserved, and no promotion of model interpretation into source truth.
4. **Gate:** Atlas/Tony Brain owners decide export scope, current source authority, rights, privacy classification, revocation and rollback. A synthetic fixture alone cannot qualify real corpus disclosure.

### Control Tower

Only observes source/build/test/PR state under its existing contracts if separately enrolled. It is not a knowledge store, semantic admission service, or duplicate publisher for this contract. No Control Tower code or runtime is added here.

## Risk, blast radius and rollback

The code change affects one static repository. A future merge to `main` could publish a new public knowledge page, machine files, sitemap entry and homepage link through the existing Netlify setup. A misclassified source could leak data to the public and persist in Git history; therefore the generator fails closed and review must inspect the exact generated bytes. The private-data scan does not replace source-owner review.

Before merge, rollback is to close the draft PR or abandon the branch. After a separately authorized public release, revert the publication commit or restore the prior successful Netlify deploy, following `README.md`. No database migration or cross-repository cleanup is needed because no adapter is active.
