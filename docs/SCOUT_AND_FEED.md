# Scout and site subscriptions

This source-only candidate adds one public Scout page and one site-wide RSS feed. The existing static generator publishes both. It does not read the Skills scanner output or private scout artifacts. The Skills #358 source custodian owns first-pass review production; the Readers publisher only admits reviewed, public-safe cards through `content/scout-public.json`.

Each Scout card needs a stable ID, original HTTPS source, review date, actual inspection method, confidence, a bounded summary, explicit unknowns, and four ratings with public source-linked rationale: GhostMesh fit, everyday usefulness, evidence strength and adoption effort. A metadata review does not claim source inspection; source inspection does not claim execution or independent measurement. Empty cards mean no candidate has yet been cleared for publication.

`content/public-release-events.json` is the one immutable public event list for the RSS feed. Add an event only for a first public Reader release, a substantive approved Reader revision, or a newly published/materially revised Scout review. Each event uses a stable subject-bound ID, canonical URL and verified public calendar date; `releasedAt` is optional and must be a genuine timezone-aware release timestamp. Date-only events have no RSS `pubDate`; the generator never invents an hour from a candidate's `published` or `updated` field. Routine builds, checks, layout changes and unpublished drafts add no event. Existing Readers are not backfilled with guessed release times. A new event is part of the normal reviewed publication source change; its RSS projection updates in the same deterministic build. RSS clients receive one item per stable event ID rather than a duplicate from each rebuild.

The new `/scout/` page currently explains the method and shows no candidate cards. It should remain empty until the Skills custodian provides real first-pass assessments and the existing Readers editorial owner clears specific public fields. This does not approve adoption, private artifact publication, new inference spending, or #45 artwork.
